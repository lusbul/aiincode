# Python × ШІ — 40 уроків

Статичний сайт для GitHub Pages. Завантажте вміст архіву в корінь репозиторію, увімкніть Settings → Pages → Deploy from a branch → main / (root).

- `index.html` — головна сторінка з 40 уроками;
- `style.css` — стилі головної;
- `lessons/lesson-01/` — готовий перший інтерактивний урок з окремими HTML, CSS, JS;
- `lessons/lesson-02/` … `lesson-40/` — заготовки.

PDF-звіт у першому уроці формується через вікно друку браузера: оберіть «Зберегти як PDF». Мініранер підтримує лише невелику підмножину Python і не виконує довільний Python-код. Симулятор ШІ не підключений до зовнішньої моделі.


## Оновлення лабораторій
Уроки 02–40 доповнені редактором справжнього Python у браузері (Pyodide, потребує інтернету під час першого завантаження), журналом дослідника, перевіркою підходу, конструктором порядку дій та тематичними завданнями. Вихідні матеріали збережено. Перший урок залишається з початковим обмеженим мініранером. PDF — через друк браузера. Для повністю автономного запуску Python потрібне локальне розміщення Pyodide.
